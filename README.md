  ## 💼 Contexto do Negócio
  Uma empresa de serviços com mais de **50.000 clientes** enfrentava um desafio crítico:
  uma taxa de cancelamento (**Churn Rate**) de **56.75%**, impactando diretamente a
  receita recorrente e a sustentabilidade do negócio.

  ## 🎯 Objetivos
  1. **Diagnóstico:** Identificar padrões de comportamento associados ao cancelamento.
  2. **Correlação:** Mapear os principais ofensores (idade, contrato e interações).
  3. **Prescrição:** Simular cenários exploratórios para apoiar decisões estratégicas de retenção.

  ## 🛠️ Tecnologias Utilizadas
  - **Python / Pandas / Plotly Express**

  ## 🔍 Principais Insights (Data Discovery)
  - 🚩 **Contratos Mensais:** Concentram praticamente todos os cancelamentos observados.
  - 🚩 **Clientes com mais de 50 anos:** Alta taxa de churn, sugerindo problemas de UX.
  - 🚩 **Fator Call Center:** Mais de 4 ligações indicam propensão crítica ao cancelamento.

  ## 📈 Resultados da Simulação (What-If)
  | Cenário | Taxa de Churn |
  | :--- | :--- |
  | **Cenário Atual** | **56.75%** |
  | **Cenário Simulado** | **9.89%** |

  ## 🧠 Conclusão
  O estudo demonstra que o churn está concentrado em poucos fatores críticos. A análise oferece uma base sólida para priorização de iniciativas e tomada de decisão orientada por dados.
